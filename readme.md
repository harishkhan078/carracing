# Car Racing Game

A simple browser-based car racing game built with HTML, CSS, and JavaScript.

## Description

This project is a classic arcade-style racing game where the player controls a car and avoids incoming traffic. The score increases over time as the player survives longer and dodges obstacles.

## Features

- Smooth road animation
- Keyboard controls with left and right movement
- Enemy cars that move downward toward the player
- Collision detection and game-over state
- Score tracking
- Restart button

## How to Play

1. Open `index.html` in your browser.
2. Use the left and right arrow keys to move your car.
3. Avoid crashing into enemy cars.
4. Try to survive as long as possible and beat your high score.

## Controls

- Left Arrow: move left
- Right Arrow: move right

## Project Structure

- `index.html` – page layout and game UI
- `style.css` – styling and game visuals
- `game.js` – game logic and controls

## Run Locally

You can either:

- open `index.html` directly in a browser, or
- run a simple local server from the project folder, for example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## Notes

This is a lightweight frontend game with no external dependencies, so it is easy to run and modify.
